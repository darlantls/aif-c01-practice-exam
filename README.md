# Practice Exam Simulators

Offline, single-file HTML practice simulators for cloud and security certifications.

Each certification lives in its own folder. Open the HTML file directly in any browser — no server, no install.

---

## Certifications

| Folder | Certification | Status |
|---|---|---|
| [`aif-c01/`](aif-c01/) | AWS Certified AI Practitioner (AIF-C01) | Available — 298 questions, 8 domains |
| [`crowdstrike-cloud-security/`](crowdstrike-cloud-security/) | CrowdStrike Cloud Security | In progress |

---

## How to Use

1. Pick a certification folder above
2. Download the `.html` file inside it
3. Open it in Chrome, Edge, Firefox, or Safari
4. No internet required after download
